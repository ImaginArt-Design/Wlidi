# 🌐 Site Web Vitrine — Wlidi (وليدي)

Site web moderne, épuré et bilingue (Arabe RTL / Français LTR) pour la présentation et le téléchargement du logiciel **Wlidi v1.0** (Assistant vocal intelligent pour la saisie des notes Massar Maroc).

---

## 📁 Arborescence du Site

```text
website/
├── index.html                  # Page principale épurée et responsive
├── favicon.ico                 # Icône officielle du site
├── Wlidi.exe                   # Exécutable portable sécurisé à télécharger (550 Ko)
├── css/
│   └── style.css               # Design SaaS Dark Slate & Émeraude, glassmorphism
├── js/
│   └── main.js                 # Moteur bilingue AR/FR instantané, accordéon FAQ, interactions
└── assets/
    ├── Wlidi_header_logo.png   # Logo officiel Wlidi avec titre
    └── Wlidi_icon.png          # Logo icône Wlidi
```

---

## 🚀 Déploiement sur GitHub Pages (1 minute)

1. Initialisez un dépôt Git dans ce dossier ou copiez son contenu dans votre dépôt :
   ```bash
   cd website
   git init
   git add .
   git commit -m "Initial commit - Wlidi Showcase Website"
   git branch -M main
   git remote add origin https://github.com/VOTRE_PSEUDO/wlidi.git
   git push -u origin main
   ```
2. Dans GitHub : rendez-vous dans **Settings** > **Pages** > sélectionnez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
3. Votre site sera immédiatement en ligne avec téléchargement direct de `Wlidi.exe` !
